## 3. 架构（ADR-3）

```
starter_kit/loomq_l2/
├── __init__.py      # agent_chat 入口：路由 + 编排
├── intent.py        # 意图分类（生成/纠错/选后端/闲聊）——LLM 一次结构化调用
├── templates.py     # 电路模板库（Bell/GHZ-n/W态/均匀叠加/翻转态/已验证），参数化生成白名单 QASM
├── generate.py      # 生成任务：模板选择+参数抽取（LLM 出 JSON）→ QASM → 本地模拟验证
├── repair.py        # 纠错任务：解析用户 QASM（错误容忍）→ 对照声明意图 → 修复/重建
├── selector.py      # 选后端：backend_capabilities.json 确定性过滤 + 规范标识注入回复
├── validate.py      # 本地验证器：parse_qasm + simulate + 分布/结构断言，产出机器可读错误
└── prompts.py       # 全部提示词（系统/意图/抽取/修复/组织答复），常量集中管理
```

关键设计：**LLM 永远不直接写 QASM 全文**——它只做意图理解和参数抽取（JSON），电路由模板库确定性生成，本地模拟器验证后输出。修复回路 = 把 validate.py 的结构化错误回喂。这保证隐藏变体下正确率天花板（QUASAR 论文已验证此路线，arXiv:2510.00967）。
