# LoomQ 量子 RISC-V 扩展指令集规格（L3 Bonus · 规格 ①）

版本：1.0 · 团队：BH2-4 · 本文档、实现与端到端测试构成 Bonus 申报三件套。

## 1. 设计目标

在官方 `TinyRISCVEmulator` 的 7 条经典指令（`li add sub addi beq bne j`）之上，
新增 **4 条量子扩展指令**，使量子操作成为 ISA 的一等公民——量子电路不再
"旁路"于经典控制流之外，而是与经典指令在同一条执行链路上顺序执行。
这正是官方 Q&A 指定的"方向 1"：指令编码实际进入可运行、可验证的执行链路。

## 2. 指令集总表

| 助记符 | 汇编格式 | 操作数 | 语义 |
|---|---|---|---|
| `QH` | `qh qi` | qi：量子比特号（立即数） | 对 q[qi] 施加 Hadamard 门 |
| `QX` | `qx qi` | 同上 | 对 q[qi] 施加 Pauli-X 门 |
| `QCX` | `qcx qc, qt` | 控制/目标比特号 | 施加受控非门 CX(qc→qt) |
| `QMS` | `qms qi, rd` | rd：通用寄存器 | 测量 q[qi]，读数写入 rd，并坍缩内部状态 |

测量规则（可复现性优先）：`QMS` 采用**确定性最大幅度读数**——
若 P(q[qi]=1) > 0.5 则读 1，否则读 0；随后将状态向量中与读数不一致的分量
清零并整体归一化（全宽度坍缩，维度不变，后续量子指令的比特下标仍有效）。

## 3. 指令编码（32 位，RISC-V 自定义扩展空间）

四条指令均落在 RISC-V 标准预留的 CUSTOM-0 opcode 空间（`opcode=0x0B`），
采用 R 型位域布局，`funct7` 区分量子操作：

```
 31        25 24    20 19    15 14 12 11     7 6      0
+------------+--------+--------+-------+---------+--------+
|  funct7    |  rs2   |  rs1   |funct3 |   rd    | opcode |
+------------+--------+--------+-------+---------+--------+
```

| 指令 | funct7 | rd | rs1 | rs2 | 示例编码（hex） |
|---|---|---|---|---|---|
| `qh qi`     | 0x20 | 0  | qi  | 0  | `qh 0` → `0x100_000B`（funct7=0x20<<25 \| qi<<15 \| 0x0B） |
| `qx qi`     | 0x21 | 0  | qi  | 0  | `qx 1` → `0x108_008B` |
| `qcx qc,qt` | 0x22 | 0  | qc  | qt  | `qcx 0,1` → `0x110_108B`（rs1=0, rs2=1） |
| `qms qi,rd` | 0x23 | rd | qi  | 0  | `qms 0,x10` → funct7=0x23, rd=10 → `0x118_500B` |

全部指令 funct3=0x0。量子比特号占 rs1（QCX 时目标在 rs2），寄存器目的占 rd
（QMS 专用，其余为 0）。编码仅占用 RISC-V 规范明确保留给厂商扩展的
CUSTOM-0 空间，不与任何标准指令冲突。

## 4. 与官方 7 指令的关系

- 扩展模拟器 `riscv_emulator_qext.py` 是官方模拟器的**超集**：官方 7 指令
  语义逐条保留（含 1000 步上限、x0 恒 0、无位宽回绕）。
- **主提交不受影响**：`compile_hybrid` 输出的汇编只使用官方 7 指令，
  可在官方原版模拟器上运行（这是 15 分主分的硬约束）。
- Bonus 通路：`qext_codegen.compile_hybrid_qext` 把量子部分编成 QH/QX/QCX/QMS，
  经典部分仍是官方指令，混合程序在扩展模拟器上一次执行完成"量子演化 →
  测量读数进寄存器 → 经典分支控制"，实现量子-经典同链路闭环。

## 5. 端到端测试（测试 ③）

```bash
python3 starter_kit/riscv_emulator_qext.py   # 模拟器自测（Bell 关联性）
python3 starter_kit/l3_selftest.py --bonus   # 200 个随机 Hybrid 用例全链路对拍
```

判定方式：随机生成 Hybrid-QASM（量子门 + 测量 + 嵌套经典控制），编译为
混合程序在扩展模拟器执行；同时用状态向量模拟器独立计算各比特的确定性
测量值，喂给经典参考解释器——两者全部寄存器终态必须一致（当前 0 失配）。

## 6. GPU 设备映射（展望，未实作）

QH/QX/QCX 天然映射为 GPU 内核：状态向量驻留显存，`qh qi` 即
`apply_h_kernel<<<…>>>(state, qi)`（逐对蝶形操作，coalesced 访问）；
`QMS` 对应两遍规约（p1 求和 + 掩码归一化）。该映射与 CUDA/OpenCL 的
量子模拟内核布局一致，规格层面即为"闭环到明确 GPU 设备指令集"预留接口。
